Açıklama

Modified build of Minion Rush Revived 9.6.1b (offline) in which the regular "Residential" map is replaced by its Halloween version (Residential Night, "rnt"). What this build changes: Modified build of Minion Rush Revived 9.6.1b (offline) in which the regular "Residential" map is replaced by its Halloween version (Residential Night, "rnt"). What this build changes: - Residential is now the Halloween (night) map in normal runs and in Despicable Ops. - Meena's boss battle works on the Halloween map (the boss minigame type was wrongly set to "None" in the original data; it is set to "Boss" here). - The regular music plays during the run instead of the boss track. Based on: Minion Rush Revived 9.6.1b offline (package com.dotxr.MinionRushRevived.offline.v961b). Only game data files were edited; no new code was added. Unofficial and untested on devices other than an Android emulator (LDPlayer). The APK is re-signed with a different key, so it cannot be installed over the original: uninstall the original first (this deletes local progress). Archive
